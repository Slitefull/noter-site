Часті питання

Як працює копія в iCloud?

Вона увімкнена за замовчуванням. Noter зберігає копію твоїх сторінок у твоєму власному iCloud, під твоїм Apple ID. Керувати нею можна в Профіль → Дані: там її можна вимкнути або зберегти копію одразу. Фото аватара й налаштування до копії не входять.

Як відновити сторінки на новому iPhone?

  1. Увійди з тим самим Apple ID і перевір, що iCloud Drive увімкнено.
  2. Встанови Noter.
  3. Профіль → Дані → Відновити з iCloud.

Відновлення лише додає або оновлює сторінки і нічого не видаляє.

Як експортувати сторінку?

На сторінці відкрий меню «…» → Експортувати. Або довго натисни картку сторінки на головному екрані. Для PDF спершу відкриється попередній перегляд.

Як експортувати все або імпортувати JSON?

Профіль → Дані → Експортувати все (JSON, CSV або Markdown). Для імпорту: Профіль → Дані → Імпортувати JSON, і обери файл з експорту чи копії Noter.

Не приходять нагадування

Дозволь сповіщення: Параметри iOS → Noter → Сповіщення. Нагадування без часу спрацьовують о 09:00.

Як змінити тему, розмір тексту чи вібровідгук?

У Профілі: Тема, Текст і Вібровідгук.

Інтерфейс застосунку лише українською. Як Noter працює з даними, описано в політиці приватності.

Common questions

How does iCloud backup work?

It is on by default. Noter keeps a copy of your pages in your own iCloud, under your Apple ID. Manage it in Профіль → Дані (Profile → Data): you can turn it off there or save a copy right away. The avatar photo and settings are not included.

How do I restore my pages on a new iPhone?

  1. Sign in with the same Apple ID and make sure iCloud Drive is on.
  2. Install Noter.
  3. Профіль → Дані → Відновити з iCloud (Profile → Data → Restore from iCloud).

Restoring only adds or updates pages. It never deletes anything.

How do I export a page?

On the page, open the "…" menu → Експортувати (Export). Or long-press the page's card on the home screen. For PDF, a preview opens first.

How do I export everything or import JSON?

Профіль → Дані → Експортувати все (Profile → Data → Export all) as JSON, CSV or Markdown. To import: Профіль → Дані → Імпортувати JSON (Import JSON), then pick a file from a Noter export or backup.

My reminders are not arriving

Allow notifications for Noter in iOS Settings → Noter → Notifications. Reminders without a time fire at 09:00.

How do I change the theme, text size or haptics?

In Профіль (Profile): Тема (Theme), Текст (Text size) and Вібровідгук (Haptics).
